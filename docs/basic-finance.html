Basic Finance

Living as God’s steward. How am I using the time, money and abilities entrusted to me?

Present live Preview slides Sign up for a cohort Join as audience Download slides

How it works

One slide at a time. Everyone takes part.

  1. Open the presenter screen.A room code and QR code appear on the projector.
  2. Everyone scans and gets a Bible name.Each person gets a random Bible-character pseudonym and portrait, and can roll again before confirming.
  3. Optional consents.Research use and future counseling contact are separate, optional choices.
  4. Answer in ranges.Income, assets and debt are answered as ranges and can be skipped. Only totals appear on screen.
  5. Guess, then check.Spending guesses, actual statements and the card-debt calculator stay private on each phone.
  6. Question → answer → compare → Scripture → application.Scripture notes are summaries; modern finance and math are applications.
  7. Finish with application and homework.Fill in four sentences and check off five home tasks, privately.

Run of show

60 or 120 minutes.
