Optional instrument recordings
==============================

The orchestra slide synthesizes every instrument in the browser, so nothing
here is required.

To use real recordings instead, add audio files named after the instrument id:

  violin  viola  cello  bass  harp
  flute  oboe  clarinet  bassoon
  horn  trumpet  trombone  tuba  timpani

e.g. oboe.mp3, cello.m4a (mp3, m4a, ogg or wav). Any instrument with a file uses
it; the others keep the synthesized part. "All together" plays every file at
once, so for that to sound right the clips should be stems of the same piece,
start at the same moment, and be the same length.

Only use recordings you have the rights to use.
